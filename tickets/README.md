# BidGuard AI Tickets

1. Find your assigned ticket in this directory.
2. Work only on the branch named in that ticket.
3. Read the whole ticket before coding.
4. Do not modify unrelated areas.
5. Run every test or verification required by the ticket.
6. Commit your completed changes with an understandable message.
7. Push your developer branch.
8. Open a pull request from your developer branch to `integration`.
9. Do not open a pull request directly to `main`.
10. Wait for Tech Lead review before the change is merged.

If work would cross into another developer's area, coordinate with that developer and the Tech Lead first.
